# Iterant

**Your agent improves itself.**

Point Iterant at your AI agent and a set of tasks with automatic checks. It proposes changes to your agent's prompts, tools and logic, tests each one in disposable sandboxes, and keeps only the changes that are statistically proven to help. Iterant never merges into your code. You review the evidence and merge.

- **Free by default.** It runs on local models through Ollama. Hosted models are opt-in, and you pay the provider.
- **Can't cheat.** Hidden checks, a locked model and budget, and an API key that never enters the sandbox.
- **Proven wins only.** Paired tests, A/A calibration and a held-out confirmation set.
